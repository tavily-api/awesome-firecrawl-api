# Awesome Firecrawl API

*Unofficial community list for Firecrawl API. Not affiliated with Firecrawl. All trademarks belong to their owners.*

A curated list of resources for the Firecrawl API, the hosted web data API that scrapes, crawls, maps and searches the web into markdown and JSON for LLM applications. Every entry links to a page that Firecrawl's site, API reference or the Vercel Marketplace listing actually points at; nothing is guessed.

> For the generation half of a scrape-then-generate pipeline: [Synexa - one REST endpoint and Python SDK for FLUX, video and audio models, pay per run](https://synexa.ai?utm_source=github&utm_medium=ugc&utm_campaign=awesome-firecrawl-api&utm_content=readme-top&utm_term=tier-r).

## Official resources

- [Firecrawl](https://www.firecrawl.dev/) - product home; search, scrape, map, crawl overview.
- [Documentation](https://docs.firecrawl.dev) - the docs site.
- [API Reference introduction](https://firecrawl-firecrawl.mintlify.app/api-reference/introduction) - base URL, authentication, getting your API key, endpoint index.
- [Rate limits](https://firecrawl-firecrawl.mintlify.app/api-reference/rate-limits) - per-plan limits.
- [Pricing](https://www.firecrawl.dev/pricing) - plans and credits.
- [Playground](https://www.firecrawl.dev/playground) - run any endpoint in the browser.
- [Blog](https://www.firecrawl.dev/blog) - announcements and integration write-ups.
- [Support](https://www.firecrawl.dev/support) - help channel linked from the marketplace listing.
- [firecrawl/firecrawl on GitHub](https://github.com/firecrawl/firecrawl) - the open source engine.
- [llms.txt for the docs](https://firecrawl-firecrawl.mintlify.app/llms.txt) - machine-readable index of the documentation.

## Getting started

- [Sign up](https://www.firecrawl.dev/signin?view=signup) - create an account and key.
- [Scrape a single URL](https://firecrawl-firecrawl.mintlify.app/api-reference/scraping/scrape) - the first endpoint to learn.
- [Map URLs](https://firecrawl-firecrawl.mintlify.app/api-reference/mapping/map) - list a site's URLs cheaply before crawling.
- [Start crawl](https://firecrawl-firecrawl.mintlify.app/api-reference/crawling/crawl) - asynchronous site crawl.
- [Get crawl status](https://firecrawl-firecrawl.mintlify.app/api-reference/crawling/get-crawl-status) - polling endpoint for crawl jobs.
- [Search](https://firecrawl-firecrawl.mintlify.app/api-reference/search/search) - web search returning page content.
- [Python SDK](https://firecrawl-firecrawl.mintlify.app/sdks/python) - the Python client.
